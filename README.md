\# SQE Gradebook



SQE Gradebook is a Java-based project developed for the Software Quality Engineering (SQE) Lab. The project focuses on managing student grade information and calculating student averages while practicing software quality engineering concepts, Git version control, branching, merging, and automated testing.



\## Installation



1\. Clone the repository:



```bash

git clone https://github.com/zuhaibahmed347/sqe-gradebook.git

```



2\. Navigate to the project directory:



```bash

cd sqe-gradebook

```



3\. Make sure Java is installed and configured on your system.



4\. Compile the Java source files using your preferred Java development environment or compiler.
